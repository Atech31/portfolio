# Abhishek Ahire | Data Analyst Portfolio

A high-performance, dark glassmorphism web portfolio showcasing data analytics projects, core competencies, artificial intelligence tools, and credentials.

![Portfolio Preview](workspace.png)

## 🌐 Live Demo

Check out the live website: **[https://atech31.github.io/portfolio/](https://atech31.github.io/portfolio/)**

---

## ✨ Features

- **Dark Glassmorphism Design:** Modern UI/UX featuring high-contrast typography, interactive cards, and responsive styling.
- **Interactive Competencies & Skills:** Categorized breakdown of tools, programming languages, databases, and AI frameworks.
- **Featured Projects:** Showcases financial, data engineering, and business analytics decision tools.
- **Credentials & Certifications:** Structured presentation of degrees, diplomas, and continuous learning badges.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Design:** CSS Grid, Flexbox, Glassmorphism Styling
- **Hosting:** GitHub Pages
- **Version Control:** Git & GitHub
